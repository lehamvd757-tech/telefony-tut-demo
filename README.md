# ТЕЛЕФОНЫ.ТУТ — demo

Статический демонстрационный интерфейс магазина «ТЕЛЕФОНЫ.ТУТ».

## Состав

- `index.html` — единственный файл интерфейса, включая CSS и JavaScript.
- `.gitignore` — исключения временных файлов и локальных секретов.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер в каталоге проекта.

## Публикация

Проект предназначен для публикации как статический сайт на Vercel. Серверная база данных, платёжные обработчики, внешние формы и аналитические трекеры не используются.

Основная ветка `main` подключена к Vercel для автоматического деплоя при push.

Все цены, наличие, отзывы, гарантийные условия, расчёты рассрочки и результаты IMEI в интерфейсе демонстрационные и требуют подтверждения. IMEI-виджет не подтверждает подлинность устройства.
